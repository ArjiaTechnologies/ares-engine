# Research and risk disclaimer

ARES Engine is research software. It does not prove profitability, does not provide financial advice,
and does not ship with order execution. Backtests and paper signals can be wrong because of data
errors, model failure, regime change, latency, spread, fees, slippage, liquidity, exchange outages,
and implementation mistakes.

The default workflow is deliberately read-only. Adding live execution is a separate safety-critical
project and should not be treated as a trivial final step.
